# HAYAOSHI LIVE — オンライン早押しクイズ大会システム

スマホが早押しボタンになる、登録不要・無料のオンライン早押しクイズ大会システムです。
HTML / CSS / JavaScript だけで動く静的サイトなので、GitHub Pages にそのまま置けます。

公開URL: https://volcanotkahasi.github.io/hayaoshi/

## できること

### 司会（ホスト）
- ルーム作成：6文字のルームコード・QRコード・参加URL（`?room=コード`）を表示。QRは拡大表示可能
- 問題の用意
  - `問題,答え` 形式のCSVを貼り付け／ファイル読み込み（スプレッドシートからのタブ区切り、`"` で囲んだ値・改行入りにも対応。見出し行は自動スキップ）
  - 1問ずつ追加、並べ替え、削除、「次に出題」で出題順のジャンプ、未出題分のシャッフル
  - サンプル20問（一般常識）を内蔵
- 読み上げ：問題文を1文字ずつ参加者の画面へ配信（速度 2〜25文字/秒）。誰かが押した瞬間に停止し、押した位置に「／」を表示
- 早押し判定：ping で各端末の時計ずれを測り、押下時刻を司会の時計に換算して最速の人に解答権（遅延補正の待ち時間は設定可能、既定 250ms）。2着以降も差（秒）を表示
- ○ / × 判定、誤答後の「続きを読む」、正解発表／スルー、読み終わり後の制限時間（既定5秒）
- ルールプリセット：**1○1×**、**7○3×**、**10up-down**、**フリー**（正解点・減点・0リセット・勝ち抜け点・失格誤答数・誤答後の休み・途中参加の可否を細かく調整可能）
- スコアボード（勝ち抜け順位・失格・休み・誤答ロック・切断の表示）
- 「元に戻す」で直前の判定を取り消し（最大30手）
- 参加者管理：加点/減点、状態変更（参加中→勝ち抜け→失格）、名前変更、退出、ping表示
- 結果のCSV書き出し（順位表＋判定ログ、Excelで文字化けしないBOM付きUTF-8）
- キーボードショートカット：`Space` 読み上げ開始/一時停止・`O` 正解・`X` 誤答・`C` 続きを読む・`R` 正解発表・`N` 次の問題・`Ctrl+Z` 元に戻す

### 参加者
- ルームコード＋ニックネームで参加（QRから開けばコード入力済み）
- 画面いっぱいの早押しボタン（PCはスペースキー／Enterでも可）、押下時のバイブ・効果音
- 流れてくる問題文、自分の得点・○×・順位・状態（解答権／誤答／休み／勝ち抜け／失格）、スコアボード

### 配信用表示（`?view=コード`）
- 大きな問題文・解答者・スコアカード。OBS のブラウザソース向け
- `&bg=transparent` で背景透過、`&bg=green` でグリーンバック、`&hidecode` でルームコード非表示、`&sound` で効果音あり

## 使い方
1. 司会がトップページで「ルームを作る」を押す
2. 参加者はQRを読み取るか、トップでコードとニックネームを入力（目安20人、上限24人）
3. 司会は「問題」タブで問題を読み込み、「ルール」タブでルールを選ぶ
4. 「進行」タブで「次の問題」→「読み上げ開始」。押されたら ○ / × で判定
5. 「結果」タブでCSVを書き出し

## しくみ・堅牢性
- 通信は [PeerJS](https://peerjs.com/)（公開クラウドのシグナリングサーバー＋WebRTC データチャネル）。サーバー側のコードは不要です
- **司会の端末が唯一の正（source of truth）**。得点・状態はすべて司会のブラウザ（localStorage）に保存され、参加者には状態のスナップショットを配信します
- 参加者の通信が切れても自動で再接続（指数バックオフ、8秒無通信で強制再接続、画面復帰時にも再接続）。リロードしても同じ参加者として復帰し、別タブで開き直しても同じ名前なら切断中の枠を引き継ぎます
- 司会がリロードしても同じルームコードを取り直して再開（トップの「前回の大会を再開」からも可）。参加者は自動で再接続します
- 読み上げタイマーは Web Worker で動かし、司会のタブが裏に回っても止まりにくくしています（ただし大会中は司会画面を前面に出しておくのがおすすめ）
- PWA 対応（ホーム画面に追加可能。Service Worker はネットワーク優先・失敗時のみキャッシュ）

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面（トップ／司会／参加者／配信用） |
| `style.css` | デザイン（ダークテーマ・モバイルファースト） |
| `app.js` | アプリ本体（通信・ゲーム進行・描画） |
| `sw.js` | Service Worker |
| `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` | PWA 用 |
| `og.png` | SNS 共有画像（1200×630） |
| `.nojekyll` | GitHub Pages 用 |

外部ライブラリは CDN（unpkg）から読み込みます：`peerjs@1.5.4`、`qrcode-generator@1.4.4`。

## 開発・テスト用
- `?transport=local` を付けると PeerJS の代わりに BroadcastChannel を使い、**同じブラウザのタブ同士**でオフライン動作します（デモ・自動テスト用）
  - 例：`/hayaoshi/?transport=local` で司会、別タブで `/hayaoshi/?room=コード&transport=local`

## 注意
- 学校・会社などのネットワークで WebRTC が制限されていると接続できない場合があります（モバイル回線への切り替えで改善することがあります）
- 公開の PeerJS クラウドサーバーは無料の共有サービスのため、混雑時に接続が遅れることがあります
- 遅延補正は端末の時計ずれと往復時間から推定するもので、通信状況によって数十ms程度の誤差があり得ます
