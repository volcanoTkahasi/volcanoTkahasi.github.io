カラーコード変換

Webデザインやスライド作りで使う色コードを、すぐに変換・コピーできます。

HEX
RGB
HSL

🔒このツールの処理はすべてお使いのブラウザ内で行われます。入力した内容やファイルがサーバーに送信・保存されることはありません。

使い方

  1. 入力欄にカラーコード（例：#FF8800）やrgb()、hsl()を入力するか、カラーピッカーで色を選びます。
  2. HEX・RGB・HSLの値が表示されます。
  3. 「コピー」でCSSにそのまま貼れる形式でコピーできます。

よくある質問

3桁のカラーコードにも対応していますか？

はい。#F80 のような3桁表記は #FF8800 として扱います。

HSLとは何ですか？

色相（Hue 0〜360°）・彩度（Saturation）・明度（Lightness）で色を表す方法です。明るさだけ変えた色を作りたいときに便利です。

コントラスト比とは？

文字色と背景色の見やすさの指標で、WCAG 2.xでは通常の本文で4.5:1以上が推奨されています。
