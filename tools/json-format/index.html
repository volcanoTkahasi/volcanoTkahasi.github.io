JSON整形・構文チェック

APIのレスポンスや設定ファイルのJSONを読みやすく整えます。

🔒このツールの処理はすべてお使いのブラウザ内で行われます。入力した内容やファイルがサーバーに送信・保存されることはありません。

使い方

  1. 整形したいJSONを入力欄に貼り付けます。
  2. インデントの種類を選び、「整形する」を押します。
  3. エラーがある場合は行・文字の位置を表示します。

よくある質問

JSONのコメントや末尾カンマは使えますか？

標準のJSON仕様（RFC 8259）に従って判定するため、コメントや末尾のカンマはエラーになります。

機密データを貼っても大丈夫ですか？

処理はすべてブラウザ内で行い、入力内容はサーバーへ送信しません。ただし共用PCでは使用後に入力欄をクリアしてください。

大きな数値の精度は保たれますか？

JavaScriptの数値として読み込むため、約16桁を超える整数は丸められる場合があります。
